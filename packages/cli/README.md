# openagentsy

The command line: set the project up (`openagentsy init`), build the agent files from the roles (`openagentsy build`), pick the models (`openagentsy models`).

## Install

```sh
`npm install -g openagentsy`
```


## Development

This package is part of the OpenAgentsy monorepo and is developed there.
