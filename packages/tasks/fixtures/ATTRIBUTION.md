# Attribution

The files in `beans-corpus/` are copies of task files from the
[hmans/beans](https://github.com/hmans/beans) repository, taken from its
`.beans/` directory (and one from `.beans/archive/`). They are there so the
store can be tested against files it did not write: a file with a parent, a
file that is blocked, a file with a manual order, a file with tags, and the
epic, milestone and scrapped variants.

Beans is licensed under the Apache License, Version 2.0. The corpus is used
as test data, unmodified; the license of the project that carries it is
recorded in the NOTICE file at the root of the repository.
